# Repository artwork

`social-preview.png` is original, AI-assisted artwork created for Vibe Racing, reviewed at its final
1280×640 size, and distributed under the repository's Apache-2.0 license. It intentionally uses no
third-party logos, vendor marks, people, cars, or product screenshots.

The canonical file is kept in the repository so the GitHub social preview can be reproduced and
reviewed like any other project asset. After changing it, verify the final dimensions and upload the
same file under **Settings → General → Social preview**.
