# Support

Vibe Racing has no production service, released connector, or supported version yet. The project
does not currently promise response times, uptime, data recovery, compatibility, or individual
installation support.

## Public questions

After the repository opens for participation, use the structured GitHub issue form that matches the
request. Search existing documentation and issues first. Share only synthetic, minimal reproduction
steps and public version information.

Do not attach raw logs, screenshots, browser exports, database copies, account identifiers, usage
data, credentials, local paths, or private conversations. A maintainer may close or redact a report
that exposes another person's data or creates a security risk.

## Security reports

Potential vulnerabilities follow [SECURITY.md](SECURITY.md). Never include exploit details or
sensitive evidence in a public support request. Conduct reports follow
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

## Unsupported requests

- Recovery of Codex, GitHub, passkey, or device accounts.
- Validation or correction of self-reported Community scores without server-verifiable evidence.
- Production deployment, migration, or backup assistance before supported operations exist.
- Private forks, custom connector builds, or environments outside the documented compatibility
  policy.
- Requests to inspect prompts, repositories, private logs, credentials, or another user's data.
- Bypasses for rate limits, safety controls, signing, source caps, or ranking rules.

Commercial support, service-level agreements, and paid moderation are not offered by this
repository.
