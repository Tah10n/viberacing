# Support

Vibe Racing is maintained on a best-effort basis.

## Where to ask

- Use the **Bug report** issue form for reproducible defects.
- Use the **Feature request** issue form for a concrete product proposal.
- Use the **Question** issue form for setup and usage help not answered by the documentation.
- Use GitHub's private **Report a vulnerability** action for security issues.

Before opening an issue, read the main [README](README.md), the connector
[README](packages/connector/README.md), and [agent support](docs/AGENT_SUPPORT.md), then search
existing issues and pull requests.

## What to include

Provide the smallest safe reproduction, expected and actual behavior, operating system, Node and
pnpm versions, connector version, and relevant sanitized diagnostics. Use synthetic data.

Never include credentials, device or pairing tokens, prompts, responses, source code, repositories,
paths, hostnames, database exports, raw agent logs, or another person's usage data.

## Scope

Maintainers may close requests that cannot be reproduced, fall outside the documented product scope,
require collecting prohibited private data, or would add an unsupported service or architecture
layer without a demonstrated production need.
